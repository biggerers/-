# 同窗进阶 · 三人共学学习闭环系统

基于 `Requirement` 目录中的产品规划需求书、商业计划书与期末目标承诺书实现的可运行 MVP。系统以“个人目标差距”为主线，覆盖学生端、小组管理端和完整学习闭环，不包含公开排名、陌生人社交或积分商城。

## 技术栈

- 前端：React 19、Vite 6、Lucide 图标、响应式 CSS
- 服务端：Node.js 22+、Express、Multer 2、bcryptjs
- PDF：PDFKit，自动寻找中文系统字体，可通过 `PDF_FONT` 指定
- 数据：单进程 JSON 原子持久化，适合三人封闭演示/试点；事务串行化保证同进程并发组卷不重复
- 测试：Node.js 内置测试运行器，包含领域规则与真实 HTTP 集成测试

## 快速启动

环境要求：Node.js 22 或更高版本、npm。

```powershell
cd tongchuang-credit-system
npm install
npm --prefix frontend install
npm run dev
```

- 前端开发地址：`http://localhost:5173`
- API 地址：`http://localhost:3000/api/health`

生产模式（前端构建后由后端统一提供服务）：

```powershell
npm run build
npm start
```

访问 `http://localhost:3000`。首次启动自动创建演示账号、四科结构、成绩目标和 48 道原创演示题。

## 已实现功能

### 学生端

- 个人总览：期中基准、当前有效总分、期末目标、达成率、剩余差距、周差距变化和分科卡片。
- 成绩与目标：成绩来源/发生时间/版本说明、学生改分申请、撤回待审申请、历史状态。
- 同伴进步：同科同口径校验、不同满分标准化、不可比原因、非排名顺序、关闭绝对分后服务端不返回相关字段。
- 练习中心：科目/分项/难度筛选、实时可用题量、题量缺口提示、A4 PDF、导出历史与下载次数。
- 用户级去重：排除当前用户全部历史导出；串行事务与唯一占用记录防止并发重复；PDF 失败释放占用。
- 试卷上传：JPG/PNG/PDF、10 MB/12 页限制、多页排序/删除、MIME 与文件头校验、OCR 确认、AI 状态跟踪。
- 错题与互助：错因归因、掌握确认、结构化求助、自愿接受/忽略。
- 个人设置：修改密码、会话失效、同伴绝对分偏好、隐私说明。

### 管理端

- 三人进度总览、待办聚合和私密异常提示。
- 用户创建、角色/状态管理、停用保留历史、一次性初始密码、重置后旧会话失效。
- 科目与分项满分配置、合计平衡校验、结构版本与调整原因。
- 成绩直接录入、学生申请通过/驳回、目标版本化与历史保留。
- AI 审核台：原卷/识别文本对照、逐题改分、低置信提示、改分理由、原子入账、驳回补图。
- 题库：单题录入、JSON 批量导入草稿、分类筛选、内容哈希查重、答案/版权上架门槛、校对与停用。
- 审计日志：账号、成绩、目标、审核、题库、导出和偏好操作留痕，不记录密码。

## 核心规则

```text
科目达成率 = (当前有效分 C - 期中基准 M) / (目标分 T - 期中基准 M) × 100%
目标差距 G = max(目标分 T - 当前有效分 C, 0)
周差距缩小率 = (上周差距 G0 - 当前差距 G1) / G0 × 100%
```

- 缺失成绩或基准显示空状态，不按 0 分计算。
- 保持目标不计算提升达成率；超额进度条封顶 100%；退步和周差距扩大保留负值。
- 学生申请通过前不改变正式成绩；审核与 AI 入账均有状态并发检查，重复请求返回 409。
- 原始试卷只对本人和管理员开放，学生之间不可见。

## 数据与配置

默认运行数据位于 `data/`：

- `data/db.json`：结构化业务数据，临时文件写入后原子替换。
- `data/uploads/`：私有原卷文件。
- `data/exports/`：生成的 PDF 与哈希对应文件。

以上运行数据均被 Git 忽略。可通过 `DATA_DIR` 修改目录。停止服务后删除 `data/db.json` 可在下次启动重新生成演示数据。

复制 `.env.example` 中的配置到进程环境即可调整 `PORT`、`DATA_DIR` 和 `PDF_FONT`。项目不依赖第三方字体 CDN 运行；界面字体加载失败时自动使用系统中文字体。

## Docker

```powershell
docker compose up --build
```

Docker 默认访问 `http://localhost:3005`（宿主机 3005 映射容器 3000），业务数据挂载到本机 `data/`。远端部署可使用 `scripts/remote_deploy.py`，SSH 密码仅通过 `DEPLOY_PASSWORD` 环境变量传入，不写入工程文件。

## AI 与生产部署边界

当前 OCR/LLM 为**明确标识的本地模拟适配器**，不会上传试卷到外部服务，也不伪装成真实模型。所有 AI 建议均必须人工复核。手工成绩、题库和 PDF 组卷不依赖 AI。

正式处理未成年人数据前，应完成监护人知情、隐私政策、第三方模型数据条款与题库版权评审；并将当前演示存储替换为关系数据库、私有对象存储、持久会话/队列和备份监控，启用 HTTPS、安全扫描与真实 OCR/LLM 适配器。本项目不构成提分或升学承诺。
